📊 Sales Performance Analytics Dashboard

Developed an interactive Sales Dashboard in Power BI to analyze business performance and provide actionable insights. The dashboard enables stakeholders to monitor sales trends, track key performance indicators, analyze category-wise performance, and make data-driven decisions through interactive visualizations and filters.

Key Features:

✅ Sales KPI Tracking
✅ Revenue Trend Analysis
✅ Category-wise Sales Performance
✅ Interactive Filters & Slicers
✅ Business Performance Monitoring
✅ Dynamic Data Visualization
